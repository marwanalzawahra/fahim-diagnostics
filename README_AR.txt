فَهِم V0.4 — ربط Supabase
=========================

1) انسخ ملفات هذه الحزمة إلى مجلد مشروعك الحالي ووافق على الاستبدال.
2) لا تحذف مجلد .streamlit الموجود لديك؛ الحزمة لا تحتوي على أي مفاتيح سرية.
3) شغّل INSTALL_ONCE.bat مرة واحدة لتثبيت المكتبات الجديدة.
4) شغّل RUN_AUTOMATED_TESTS.bat. النتيجة المتوقعة: Ran 3 tests ثم OK.
5) شغّل RUN_SUPABASE_TEST.bat. يجب ظهور رسالتي OK، ثم يُحذف سجل الاختبار المؤقت.
6) شغّل START_FAHIM.bat وأكمل محاولة تجريبية.
7) افتح Supabase > Table Editor للتحقق من ظهور المحاولة وإجاباتها.

الأمان:
- لا ترسل أو ترفع ملف .streamlit/secrets.toml.
- لا تضع SUPABASE_KEY داخل app.py.
- عند فشل الإنترنت، يبقى pilot_results.csv نسخة محلية احتياطية.
إضافة V0.5: لوحة المعلّم
======================

1) افتح ملف .streamlit\secrets.toml وأضف سطرًا جديدًا:
   TEACHER_PASSWORD = "كلمة_مرور_قوية_خاصة_بك"

2) شغّل INSTALL_ONCE.bat مرة واحدة لتثبيت/تحديث المتطلبات.

3) لتشغيل اختبار الطالب استخدم START_FAHIM.bat.

4) لتشغيل لوحة المعلّم استخدم START_TEACHER_DASHBOARD.bat.

تقرأ لوحة المعلّم بيانات Supabase دون تعديلها، وتعرض:
- عدد الطلاب والمحاولات ومتوسط الأداء.
- جدول المحاولات مع التصفية حسب الطالب والاختبار.
- أكثر الأسئلة وأنماط الخطأ تكرارًا.
- تفاصيل كل إجابة داخل محاولة محددة.
- تنزيل ملخص المحاولات بصيغة CSV.

تنبيه أمني: لا ترسل ملف secrets.toml إلى الطلاب ولا ترفعه إلى مستودع عام.
